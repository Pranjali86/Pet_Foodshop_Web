# Pet_Foodshop_Web
A responsive pet food e-commerce landing page built using HTML, CSS, and JavaScript.
This project is designed as a modern, clean, and user-friendly website for showcasing pet products, with smooth interactions and responsive layouts.

🚀 Features

✅ Responsive Header & Navigation with toggle menu

✅ Sticky Header that activates on scroll

✅ Back-to-Top Button for smooth navigation

✅ Reusable Components (cards, sections, buttons)

✅ Clean & Modern UI Design

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (Vanilla JS)

Fonts & Icons: Google Fonts, Font Awesome

📂 Project Structure
.
├── index.html         # Main HTML file

├── style.css          # Custom CSS for styling

├── script.js          # JavaScript for interactivity

└── README.md          # Project documentation
